# 読めない博物誌

AIの潜在空間のなかで「既存のどの生きものにも似ない」ように探索された生きものを収めた図鑑。
各標本には名前がある。名前は、語彙の空間におけるその生きものの座標から、ひとつの規則で書かれている。
人間の言葉で書けるのは、それが「何でないか」だけである。

## 作品の仕組み

| 頁の要素 | 中身 | 出どころ |
|---|---|---|
| 図版 | 生きものの姿 | ConceptLab が学習した擬似単語で Kandinsky 2.1 が生成 |
| 名前（縦書き） | 属名 2 字 ＋ 種名 2–5 字 | 擬似単語の座標（CLIP ViT-L/14 語彙空間の主成分）を文字に写したもの |
| 記載 | 読めない文字の短い文 | その生きものにもっとも近い既知の語 12 個を、同じ文字で書いたもの |
| これではないもの | 読める唯一の説明 | 学習中に BLIP-2 が「これは何か」と答え、そこから遠ざけられた語の履歴 |
| 手がかり（巻末） | 既知の語とその表記 | human, cat などを同じ規則で書いたもの |

### 文字の規則（`book/glyphs.js`）

- 座標は、CLIP の語彙のうち英単語として完結するトークン（数万語）の主成分 56 軸で表す。各軸は語彙全体の標準偏差で割って揃える。
- 1 文字が 8 次元を受け持つ。3×3 の格子の上に、20 本の候補から 4 本前後の画が現れる。
- 8 次元の**向き**が字形を、**大きさ**が墨の濃さを決める。
- 属名は主成分 1–16（語彙全体の大きな違い）、種名は 17 以降（細かな違い）から書く。近縁の標本は属名を共有しやすい。
- 字形は座標の連続関数で決まる。座標が少し動けば字形も少しだけ動き、急に切り替わることはない。
- 種名の長さは「既知の語からの遠さ」で決まる。既知の語は 1 字、本に収めた標本のなかで最も遠いものは 5 字。
- 表紙の文字列は全標本の座標の重心、部扉の文字は各部の重心の属名。

## ファイル

```
yomenai-hakubutsushi/
├── colab/01_generate_specimens.ipynb  標本・図版・座標を生成する（Google Colab・GPU）
└── book/
    ├── index.html        図鑑本体（B5・印刷用）
    ├── script-lab.html   文字の規則が連続性・近縁性を満たすかの検証ページ
    ├── glyphs.js         座標 → 文字 の規則
    ├── mock-data.js      試作用のダミーデータ（本物があれば使われない）
    └── data/             Colab の出力（specimens.js と images/）をここに置く
```

## 制作の流れ

1. `colab/01_generate_specimens.ipynb` を Google Colab で開き、GPU ランタイム（A100 推奨）で上から実行する。
   最初は `SMOKE_TEST = True` のまま 1 体だけ試運転し、動作を確かめてから `False` にする。
2. Google ドライブにできる `yomenai-hakubutsushi/book_data.zip` を展開し、中身を `book/data/` に置く。
3. `book/index.html` をブラウザで開く。ローカルで開く場合は、`book/` で `python3 -m http.server` を起動して `http://localhost:8000` を開くと確実。
4. 印刷するときは、ブラウザの印刷で用紙 B5・余白なし・背景を印刷、を指定する。

## 国際AIクリエイターアワード2026 への応募

- 応募内容の下書き・日程・注意点：`entry/application.md`（手元のみ。リポジトリには含めない）
- 応募画像と PDF の書き出し：`bash tools/export.sh`（Google Chrome を使う。引数で主役の標本番号を選べる）
  - `entry/out/` に 1:1・16:9（カバー／文字なし）・2:3 の 4 枚、`book/` に PDF と共有用画像ができる
  - 試作データのまま書き出したものは仮。本物のデータを `book/data/` に置いてから書き出し直す
- 公開するのは `book/` フォルダ一式（`data/` と PDF を含む）。公開先が決まったら `index.html` の og:image を絶対 URL に直す

## これから決めること

- 部の構成とカテゴリ語（creature / plant / insect …）、各部の体数
- 図版のプロンプト（銅版画風の標本図、生息地の写真、標本箱 …）と、どの seed を主図版にするか
- 否定語を英語のまま載せるか、和訳するか（`negatives_ja` を足すと和訳が使われる）
- 巻末の「手がかり」を載せるか。載せれば「読めないが、読み方は存在する」ことの証拠になり、外せば完全に閉じた本になる
- 判型・紙・製本
